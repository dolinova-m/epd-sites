# Материалы по ЭПД — статические страницы

Клиентские инструкции и калькулятор тарифов «Платформы ЭПД». Обычные html-страницы
без сборки и внешних зависимостей: шрифты системные, картинки рядом в папках,
логотипы встроены в html.

Открыть: **https://dolinova-m.github.io/epd-sites/**

| Папка | Что это |
|---|---|
| [`epd-perevozchiki/`](epd-perevozchiki/) | Методичка для перевозчиков: переход на ЭПД для ИП за рулём и для перевозчика с наёмными водителями |
| [`epd-instrukciya/`](epd-instrukciya/) | Кто что подписывает в ЭПД — по роли: документы, тарификация, вид подписи |
| [`epd-podpisi/`](epd-podpisi/) | Электронные подписи: Госключ, МЧД, РуТокен с NFC |
| [`epd-kalkulyator/`](epd-kalkulyator/) | Квиз-калькулятор тарифов, заявка уходит менеджеру |

## Правки

Это **зеркало для публикации**, а не место для работы. Исходники страниц и вся
база знаний живут в приватном репозитории; сюда файлы копирует скрипт
`инструменты/деплой/pages-sync.sh` из него. Правки, сделанные здесь руками,
будут затёрты следующей синхронизацией.

Публикуется через GitHub Pages из ветки `main` (корень). Файл `.nojekyll` нужен,
чтобы Pages отдавал папки с русскими именами как есть, без обработки Jekyll.
